GitHub 节点源 · 怎么找、怎么填

          
          
        

        

          

            ① 去哪找
            
GitHub 上有一批每天自动更新的代理清单仓库。按「最近更新」排序、
              挑 star 多且提交活跃的，比按 star 排更靠谱——老仓库的 IP 早就死了。

            

              搜 proxy list ↗
              搜 free proxy list ↗
              搜 socks5 proxy list ↗
            

          

          

            ② 认清单文件
            
进仓库看根目录（或 protocols/、proxies/ 这类子目录），
              文件名通常是 http.txt、socks5.txt、
              proxies.txt、all.txt。
              只有代码没有 txt 的仓库抓不到东西。

          

          

            ③ 怎么填
            
整仓抓填 owner/repo；只抓某个子目录填
              owner/repo/tree/分支/目录。

              例：officialputuid/KangProxy　
              databay-labs/free-proxy-list/tree/master/by-country/us
